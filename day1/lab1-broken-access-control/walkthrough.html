Broken Access Control on an Admin Endpoint

The store gates the "Buy Flag" button to user id 2, who only starts with 10 coins. The admin profile shows a wallet-update form, but the endpoint behind it never checks who is calling it. Any logged-in user can top up any wallet.

Quick Reminder — Broken Access Control

Broken access control happens when the server trusts the client to enforce who can do what. Hiding a button in the UI is not authorization; the route handler must check the caller's role itself.

In this lab the impact is privilege escalation through state tampering: a regular user reaches an admin function to give themselves the coins they need to buy the flag.

Where the vulnerability comes from

The wallet-update route accepts any authenticated session and writes the new balance straight in. There is no role check.

@app.route("/admin/update_wallet", methods=["POST"])
def update_wallet():
    data = request.get_json(silent=True) or {}
    uid = int(data.get("id", 0) or request.form.get("id", 0))
    new_sold = int(data.get("sold", 0) or request.form.get("sold", 0))
    if uid in users:
        users[uid]["coins"] = new_sold
        return ...

The form that calls this endpoint is rendered only inside the admin profile. That is a UI affordance, not a security control. The route is reachable by anyone who knows the path.

Exploitation

Log in as the regular user, then send the admin form's request directly. Use the same field names the admin's form uses (id and sold).

Login

username=user
password=user123

Request the "admin" endpoint as the regular user

curl -i http://localhost:5009/admin/update_wallet \
  -b cookies.txt \
  --data "id=2&sold=999"

The server accepts the request, writes 999 coins to user id 2, and redirects back to the profile. Visit the store and click Buy — the flag is yours.

The Fix

Authorization belongs on the server. Decide what an admin is, and reject the request before doing any work.

def is_admin(u):
    return u and u["id"] == 1

@app.route("/admin/update_wallet", methods=["POST"])
def update_wallet():
    cu = current_user()
    if not is_admin(cu):
        return "forbidden", 403
    # ... rest of the handler

Two reinforcing rules to remember:

  • Hiding a control in the UI is not access control.
  • Every privileged endpoint must verify the caller's identity and role itself, on every request.
